# transport_project

You should have forked and cloned my transport_project repository locally, created a conda environment using transport_environment.yml, and launched a python IDE.

transport_environment.yml: This file contains the dependencies for the conda environment, to enable the program operation.
  This also makes available JupyterLab and other tools.

London_data: this is the file containing real datasets required by the programs for analysis.

Cycle_program: This program runs using dependencies in the transport_environment, and the data in London_data.

PT_Method: This program runs like Cycle_program, but it uses Folium and automatically opens browser, without modification (see How-to Guide).

The two workbook files are previous development, debugging and troubleshooting (behind the scenes). Open these in JupyterLab.
